# Александр Карпоченко — Portfolio Site

Personal portfolio of Alexander Karpochenko, Python backend developer.

**Live site:** [aleksand112.github.io](https://aleksand112.github.io)

## Stack

- Pure HTML/CSS/JS — no frameworks, no build step
- Hosted via GitHub Pages

## Structure

```
index.html          # Main page (single-page portfolio)
screenshots/        # Project screenshots (used in portfolio section)
Фото/               # Personal photos (used in About section)
.nojekyll           # Disables Jekyll processing on GitHub Pages
```

## Local development

Just open `index.html` in a browser — no server needed.

## Deploy

Any push to `main` branch automatically deploys to GitHub Pages.
